# User test: first-open flow, paper prototype

Date: 2026-11-20
Method: paper walkthrough by user-simulator

## Personas
- First-timer
- Power user
- Distracted mobile user
- Accessibility-dependent user

## Blockers
- Accessibility-dependent user cannot find the skip control on the Help me now sheet (screen reader reaches it only after the full text)

## Friction
- First-timer hesitates at the two doors; the labels do not say which one is for setup
- Distracted mobile user loses their place when the sheet is dismissed by accident
